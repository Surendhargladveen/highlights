Key Features:
-------------
✅ Refactored from 1 huge file (1485 lines) to 6 focused controllers
✅ All functionality preserved - works exactly the same
✅ Clean separation of concerns
✅ Easy to maintain and debug
✅ Proper connectivity between all components

Controllers Breakdown:
---------------------
1. DashboardController  - Main entry point, statistics, graphs
2. NavigationController - Left panel navigation, routing
3. CustomerController   - Add/Edit/Delete/Search customers, purchase history
4. ProductController    - Product catalog management
5. InvoiceController    - Invoice creation, PDF generation, invoice history
6. ProfitCalculatorController - Profit margin calculations

Database Tables:
---------------
- customers       (Customer data)
- products        (Product catalog)
- invoices        (Invoice headers)
- invoice_items   (Invoice line items)
- users           (Application users)

How to Build & Run:
------------------
1. Ensure Java 8+ and Maven are installed
2. Run: mvn clean compile
3. Run: mvn exec:java
   OR use build.bat and run.bat (Windows)

Technology Stack:
----------------
- Java 8+
- JavaFX (UI Framework)
- SQLite (Database)
- Maven (Build Tool)
- iTextPDF (PDF Generation)

Migration from Old Code:
-----------------------
If you have the old single-file DashboardController:

1. Backup your current project
2. Delete: src/main/java/com/Highlights/controller/DashboardController.java
3. Copy ALL files from this refactored project
4. Build and run

No database changes required!
No model changes required!
